# Terminal Basics (2-minute orientation)

## What is a terminal?

A terminal is a text-based window where you type commands and press Enter. Think of it like texting your computer instead of clicking buttons. You type something, hit Enter, and it responds.

## How to open a terminal

**Mac:**
- Open Spotlight (Cmd + Space), type "Terminal", press Enter
- Or go to Applications > Utilities > Terminal

**Windows:**
- Press the Windows key, type "Command Prompt" or "PowerShell", press Enter
- Or press Win + R, type `cmd`, press Enter

## What happens when you type `claude`

Once Claude Code is installed, typing `claude` and pressing Enter starts an interactive conversation. You'll see a prompt where you can type plain English — things like "Help me build my experience library" or paste a job description. No coding knowledge needed.

## What are .md files?

Files ending in `.md` are Markdown files — just plain text with simple formatting (like `#` for headings and `**bold**` for bold text). You can read and edit them in any text editor.

**To read them with nice formatting:**
- In Cursor or VS Code: right-click the file > "Open Preview"
- On GitHub: they display formatted automatically
- In any text editor: they're perfectly readable as plain text too

## Navigate to the Job Search OS folder

Before typing `claude`, you need to be in the right folder:

- **Easiest way:** Type `cd ` (with a space after it), then drag the `job-search-os` folder from Finder (Mac) or Explorer (Windows) into the terminal window. Press Enter.
- **Or type the path directly:** `cd ~/Downloads/job-search-os` (adjust if you put it somewhere else).
