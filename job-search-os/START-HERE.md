# Start Here

## Before You Start

You need four things:

1. **A Claude subscription.** Claude Pro ($20/month) or Max ($100/month) at [claude.ai](https://claude.ai). This gives you access to Claude Code.
2. **Claude Code installed.** Follow the quick install at `setup/installation-guide.md` (takes 5 minutes). Once installed, you type `claude` in a terminal and start talking.
3. **A code editor or terminal.** [Cursor](https://cursor.com) is recommended (free, has a built-in terminal). [VS Code](https://code.visualstudio.com) also works. Or use any terminal app directly.
4. **Your resume and LinkedIn text.** Have your current resume and LinkedIn profile ready to paste. You'll need both during setup.

**Time commitment:** About 45 minutes for first setup. After that, 20-30 minutes per day.

**What is Claude Code?** It's a tool that runs in a terminal (the text-based command window on your computer). You type a command, press Enter, and Claude responds. No coding required — you'll mostly type plain English and paste job descriptions.

New to terminals? See `setup/terminal-basics.md` for a 2-minute orientation.

Welcome to Job Search OS. Here's how to get running in 45 minutes.

## Try It Now (2 min)

Open this folder in your editor, start Claude Code in the terminal (`claude`), paste any job description, and run `/quick-start`. No setup needed. In 60 seconds you'll know if the role is worth your time: red flags, salary estimate, and interview intel.

## Full Setup (45 min)

1. **Build your experience library** (20 min) -- Say `Help me build my experience library`. Paste your resume and LinkedIn. Claude organizes everything and builds your story bank. See `setup/example-experience-library.md` for what "done" looks like.
2. **Fill your career plan** (10 min) -- Say `Help me fill out my career plan`. Define your level, industry, weaknesses, and dream offer. See `setup/example-career-plan.md` for a filled example.
3. **Fill the Q&A master doc** (10 min) -- Say `Help me fill out the Q&A master doc`. Cover comp strategy, common questions, logistics.
4. **Generate target companies** (5 min) -- Run `/company-research generate target list`. Review and reorder the top 10.
5. **Set up morning briefing** (optional) -- See `setup/morning-briefing-setup.md` for Cowork automation.

After setup, your daily routine takes 20-30 minutes.

## Your First 5 Commands

Run these in order after setup. Each one builds on the last.

1. `/quick-start [paste any JD]` — Is this role worth your time? Red flags, salary, interview intel. 60 seconds, zero setup.
2. `Help me build my experience library` — The foundation. 20 min of talking = sharp output everywhere.
3. `Help me fill out my career plan` — Targeting + weakness analysis. Drives everything.
4. `/resume-tailor [paste a JD]` — Your first tailored resume. Compare it to what you had before.
5. `/connection-request` — Your first batch of networking outreach. Pipeline starts here.

## What to Do Each Week

**Week 1:** Set up context library. Run `/resume-tailor` and `/connection-request` daily. Submit 3-5 targeted applications.

**Week 2:** Add `/job-fit-scorer` before tailoring. Start `/referral-request` for roles you've applied to. Build first `/work-product` for your top company.

**Week 3+:** Interview system kicks in. Run `/interview-prep` before each interview. `/mock-interview` the night before. `/interview-debrief` after. `/thank-you-note` same day. `/weekly-retro` every Friday.
